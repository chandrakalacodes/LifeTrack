# LifeTrack

LifeTrack is a simple personal productivity dashboard that helps users manage their daily tasks, set goals, track progress, and stay focused.

## Features

- Add, complete, and delete tasks
- Manage tasks for different dates
- Set personal monthly and yearly goals
- Track daily, monthly, and yearly progress
- Track daily streaks
- Built-in focus timer
- Calendar with month and year navigation
- Data is saved in the browser
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How It Works

Users can select a date, add their tasks, create their own goals, and track their progress. The data is saved in the browser using LocalStorage, so it can be accessed again from the same browser.

## Project Goal

I built LifeTrack as a personal productivity project to practice frontend development and create something useful for everyday planning and task management.
